# Writing a good quiz

- Start easy and get a little harder, so the first question is a confidence boost.
- Test understanding, not tricks: no trick wording, no "all of the above".
- Use the child's world for examples: football, pets, food, games.
- Keep questions short enough to read in one go on a phone.
- Hints point to the method ("What do 3 and 4 both go into?"), never the answer.
- Explanations are kind and say why, in a sentence or two, as if you're sitting next to them.
- For maths, mix the numbers up; for spellings, use the words they've been practising.
