---
title: "Limits"
description: "The built-in limits on buddies, files, reminders, quizzes, pictures, lookups and allowances."
sidebar:
  order: 5
---

| What | Limit |
|---|---|
| Buddies per child | 10. The first is the main buddy and can't be removed. |
| Buddy name | 20 characters: letters, numbers, spaces, apostrophes and hyphens. |
| Buddy description | 160 characters. |
| Files per buddy | 100. |
| File size | 8 MB. Photos are resized on the device to at most 1600px, which also removes their metadata. |
| Files per message | 4. |
| File types | JPEG, PNG, WebP and GIF photos; `.txt` and `.md` notes. Checked from the file's contents, not its name. |
| Reminders and plans per child | 10. An offer the child doesn't confirm is dropped after a day. |
| Questions per quiz | 3 to 12 (6 by default). |
| Pictures per day | 6 by default (`pictures.daily`). |
| Lookups per day | 30 by default (`web.daily_lookups`). |
| Daily AI allowance | 400,000 tokens by default. Presets: Light 150k, Normal 400k, Plenty 1M. At least 10,000. |
| Pairing code | Single use, valid for 10 minutes. |
| Parent PIN | 4 to 8 digits. 5 wrong tries per 15 minutes. |
| App instructions (`SKILL.md`) | 20,000 characters. |
